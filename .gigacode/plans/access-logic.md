 # Логика системы доступа (SIS.SITE v1.0)

## Назначение
Система управления доступом к локальным файлам для обхода CORS в офлайн-режиме.

## Основные принципы
- **Проверка localhost** — определяет, доступен ли сервер ( CORS позволяет работать с файлами )
- **Кнопка "Получить доступ"** — появляется ТОЛЬКО если localhost недоступен
- **Уровень доступа 1** — выдается при нажатии кнопки, позволяет работать с новостями
- **Кэширование** — проверка localhost происходит ОДИН РАЗ, результат сохраняется в localStorage

## Ключевые ключи localStorage
| Ключ | Значение | Описание |
|------|----------|----------|
| `localhost_checked` | `'true'` | Проверка localhost уже выполнена |
| `localhost_has_access` | `'true'` / `'false'` | Результат проверки localhost |
| `permissions_granted` | `'true'` | Пользователь получил доступ (кнопка нажата) |

## Логика работы

### 1. Инициализация (при загрузке страницы)
```
PermissionManager.init()
  ↓
checkLocalhostAccess()
  ↓
Проверяем кэш:
  - Если localhost_checked === 'true':
    → используем сохраненное значение localhost_has_access
    → пропускаем проверку
  - Если нет:
    → делаем fetch('/api/check-access') с таймаутом 2с
    → сохраняем результат в localStorage
    ↓
Если localhost_has_access === 'true':
  → кнопка НЕ показывается
  → нормальная загрузка страницы
Иначе:
  → показываем кнопку "Получить доступ"
```

### 2. Нажатие кнопки "Получить доступ"
```
requestAccess()
  ↓
Проверяем, есть ли сохраненный уровень:
  - Если level > 0:
    → используем сохраненный уровень
  - Иначе:
    → выдаем уровень 1 (временный)
  ↓
grantPermission()
  → сохраняем permissions_granted = 'true'
  → скрываем кнопку
  → добавляем класс access-granted
```

## Где появляется кнопка
- ✅ Только на странице новостей (где есть `.add-news-btn`)
- ✅ Только если `localhost_has_access === 'false'`
- ❌ Не появляется, если localhost доступен
- ❌ Не появляется на других страницах (about, contacts, etc.)
