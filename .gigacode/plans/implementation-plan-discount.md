# Implementation Plan: Discount Popup (Круглая кнопка со скидкой)

## 🎯 Цель
Реализовать функционал круглой кнопки со скидкой (%) и крестиком (X) для закрытия окна на странице `actions.html`.

## 📝 Задачи

### 1. Создать JS модуль (discount-popup.js)
- [x] Создать класс `DiscountPopup` в `.gigacode/plans/discount-popup.js`
- [x] Добавить методы: `initElements()`, `setupEventListeners()`, `checkIfClosed()`, `show()`, `hide()`, `close()`, `reopen()`
- [x] Обработка клика по кнопке закрытия (крестик)
- [x] Обработка Esc для закрытия
- [x] Сохранение состояния в localStorage

### 2. Создать CSS стили (discount-popup.css)
- [x] Стили для контейнера `.discount-popup-container`
- [x] Стили для круглой кнопки `.discount-popup`
- [x] Стили для процента скидки `.discount-percent`
- [x] Стили для кнопки закрытия `.discount-close`
- [x] Анимация появления (`discountPopIn`)
- [x] Адаптивность для мобильных устройств

### 3. Интеграция в actions.html
- [ ] Добавить `<script type="module" src="static/js/discount-popup.js"></script>` в `<head>`
- [ ] Добавить `<link rel="stylesheet" href="static/css/discount-popup.css">` в `<head>`
- [ ] Проверить работу кнопки

### 4. Тестирование
- [ ] Проверить появление кнопки при первом заходе
- [ ] Проверить закрытие по крестику
- [ ] Проверить закрытие по Esc
- [ ] Проверить сохранение состояния (после закрытия кнопка не появляется)
- [ ] Проверить повторное открытие через `window.discountPopup.reopen()`

## 🔧 Тестовые сценарии

### TC-7.1: Базовое отображение
- [ ] При первом заходе на `actions.html` появляется круглая кнопка со скидкой 15%
- [ ] Кнопка имеет градиентный фон (красный/оранжевый)
- [ ] Кнопка имеет крестик (X) в правом верхнем углу

### TC-7.2: Закрытие кнопки
- [ ] При клике на крестик кнопка исчезает
- [ ] При нажатии Esc кнопка исчезает
- [ ] При клике на кнопку закрытие не происходит (только на крестик)

### TC-7.3: Сохранение состояния
- [ ] После закрытия кнопка не появляется при перезагрузке страницы
- [ ] localStorage содержит `discount_popup_closed: true`

### TC-7.4: Повторное открытие
- [ ] Вызов `window.discountPopup.reopen()` снова показывает кнопку
- [ ] localStorage очищается при повторном открытии
