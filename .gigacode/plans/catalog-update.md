# План обновления страницы catalog.html

## Цель
Сделать страницу catalog.html похожей на news.html с формой, содержащей две закладки: "Новости" и "Товары".

## Что нужно сделать

### 1. Обновить catalog.html
- Добавить CSS стили для каталога (аналогично news.css)
- Добавить стили для закладок в форму (tabs)
- Добавить HTML структуру:
  - Панель заголовка с кнопкой "Добавить лот"
  - Контейнер для карточек товаров
  - Модальное окно с закладками для новостей и товаров

### 2. Создать catalog.js
- Обработка переключения закладок
- Рендеринг карточек товаров
- Обработка отправки формы для товаров

### 3. Обновить main.js (если нужно)
- Добавить поддержку catalog.js

## Структура формы с закладками

```
Модальное окно:
  - Заголовок: "Добавление лота"
  - Закладки:
    * Новости (кнопка)
    * Товары (кнопка)
  - Контент закладок:
    * Новости: image, title, date, preview, content
    * Товары: productImage, productName, productPrice, productDescription
  - Кнопки: "Сохранить", "Отмена"
```

## Примечания
- Использовать те же стили, что и в news-form.css
- Форма должна открываться на нужной закладке при клике на "Добавить лот"
- Кнопка "Добавить лот" находится в панели заголовка
