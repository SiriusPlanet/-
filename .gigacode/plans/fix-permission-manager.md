# План исправления permission-manager.js

## Проблема
Кнопка "Дать доступ" не работает на страницах, отличных от news.html (например, на index.html), потому что в методе `init()` есть проверка:
```javascript
const newsButton = document.querySelector('.add-news-btn');
if (!newsButton) {
    return; // МОДУЛЬ ЗАВЕРШАЕТ РАБОТУ
}
```

## Дополнительная проблема (выявлено после исправления)
Показ завесы **ДО** проверки доступа вызывает рендеринг, который может быть заметен глазу (600мс вместо 2мс).

## Решение (оптимизированное)
Изменить логику `init()`:

1. **Проверка разрешения — синхронная, мгновенная** (2мс)
   - Если есть `permissions_granted` в localStorage → продолжаем работу без паузы
   - Если есть `localhost_has_access=true` в localStorage → продолжаем работу без паузы

2. **Проверка localhost — фоновая** (2сек таймаут)
   - Не показываем завесу пока идет проверка
   - Если проверка успешна (доступ есть) → убираем завесу, продолжаем работу
   - Если проверка провалилась (доступа нет) → показываем завесу с кнопкой

3. **Завеса показывается ТОЛЬКО если проверка выявила отсутствие доступа**

## Изменения
- Добавить метод `hasGrantedPermission()` для проверки сохраненного разрешения
- Изменить логику `init()` чтобы она работала на всех страницах
- Вешать событие на кнопку ТОЛЬКО после того, как проверка localhost выявила отсутствие доступа
- Проверка кэша (`localhost_has_access`) — быстрая (2мс), продолжаем работу без паузы
