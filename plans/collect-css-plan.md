# План объединения CSS файлов

## Текущее состояние

### Файлы CSS в `static/css/`:
1. `style.css` - основной файл (1200+ строк) - содержит большую часть стилей
2. `news.css` - дополнительные стили для новостей и каталога (800+ строк)
3. `about_page_styles.css` - стили для страницы "О нас" (250+ строк)
4. `news-form.css` - стили для формы добавления новостей (уже встроены в `news.css`)
5. `#privacy.css` - стили для политики конфиденциальности (100+ строк)
6. `style02.css` - альтернативная версия стилей (аналог `style.css`)

### Проблемы:
1. **Дублирование**: `style02.css` содержит аналогичные стили `style.css`
2. **Форма новостей**: `news-form.css` уже встроена в `news.css`
3. **Разбросанные стили**: Некоторые стили дублируются в разных файлах
4. **HTML подключают несколько CSS**: `news.html` и `catalog.html` подключают `news-form.css`

## Цель

Создать единый CSS файл `style.css`, который содержит все необходимые стили без дублирования.

## План действий

### Шаг 1: Анализ дублирования (создать карту совпадений)
- Сравнить `style.css` и `style02.css` - найти совпадающие селекторы
- Сравнить `news.css` и `style.css` - найти дублирующие стили новостей
- Определить приоритеты для каждого селектора

### Шаг 2: Объединение CSS файлов (в порядке приоритета)

#### 2.1 Основа: `style.css` (базовый файл)
- Сброс и базовые стили
- Шапка и навигация
- Каталог товаров
- Новости (базовые)
- Модальные окна
- Футер
- Адаптивность

#### 2.2 Добавить из `about_page_styles.css`:
- Пастельные подложки для секций о нас
- Memory-fragment стили
- Timeline
- Principles-grid

#### 2.3 Добавить из `news.css` (если нет в `style.css`):
- Специфичные стили для карточек каталога (`.catalog-card`)
- Бейдж скидки (`.discount-badge`)
- Кнопки управления (`.del-btn`, `.edit-btn`, `.discount-btn`)
- Модальное окно детального просмотра (`#detailModal`)
- Модальное окно добавления новости (`#addNewsModal`)
- Табы формы
- Файл-апло��д
- Reactor subcatalog
- Дизайнерское оформление "Топ 3" (`.index-catalog`)
- Карточки компактные и крупные (`.card-compact`, `.card-large`)

#### 2.4 Добавить из `#privacy.css`:
- Стили для политики конфиденциальности

#### 2.5 Удалить `news-form.css` из HTML
- Убрать подключение из `news.html` и `catalog.html`
- Убедиться, что стили формы уже в `news.css`

### Шаг 3: Оптимизация

#### 3.1 Удалить дублирующиеся правила
- Найти селекторы, которые определены несколько раз
- Оставить только последнее определение (оно переопределит предыдущие)

#### 3.2 Удалить неиспользуемые стили
- Проверить, какие стили реально используются в HTML
- Удалить мёртвый код

#### 3.3 Минимизация (опционально)
- Удалить комментарии
- Удалить пустые строки
- Сократить размер файла

### Шаг 4: Тестирование

#### 4.1 Проверить каждую страницу:
- `index.html` - главная, Топ 3, новостная лента
- `news.html` - новости, форма добавления
- `catalog.html` - каталог товаров
- `actions.html` - акции
- `about.html` - о нас
- `contacts.html` - контакты
- `delivery.html` - доставка
- `requisites.html` - реквизиты
- `privacy.html` - политика конфиденциальности

#### 4.2 Проверить адаптивность:
- Мобильные устройства (max-width: 480px)
- Планшеты (max-width: 768px)
- Десктопы (max-width: 1024px)

### Шаг 5: Резервное копирование и внедрение

#### 5.1 Создать бэкап текущих файлов
- Скопировать `static/css/` в `static/css_backup/`

#### 5.2 Создать единый `style.css`
- Объединить все стили в один файл

#### 5.3 Обновить HTML файлы
- Убрать подключение лишних CSS файлов
- Оставить только `style.css`

#### 5.4 Удалить старые файлы (после тестирования)
- `news.css`
- `about_page_styles.css`
- `news-form.css`
- `#privacy.css`
- `style02.css`
