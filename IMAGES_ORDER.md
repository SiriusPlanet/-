# Организация изображений в проекте

## Структура папок

```
images/
├── logo.png          # Основной логотип сайта (используется на всех страницах)
├── 1.png             # Товары в каталоге (статичные изображения)
├── 2.png
├── 3.png
├── 4.png
├── 5.png
├── 6.png
├── 7.png
├── 8.png
├── 90.png
├── 91.png
├── 92.png
├── 93.png
├── 94.png
├── BG.jpg            # Фоновое изображение
└── img_n/            # Папка для новостных изображений
    ├── 1781002918303.jpg  # Автоматически сгенерированные имена (timestamp)
    ├── 1781002918608.jpg
    └── ...             # Другие загруженные пользователем картинки
```

## Принцип разделения

### `images/` (корень)
- **Назначение**: Статичные изображения сайта
- **Картинки**: logo.png, товары (1.png, 2.png, 3.png и т.д.), фон BG.jpg
- **Использование**: Прямые пути в HTML (`<img src="images/logo.png">`)

### `images/img_n/`
- **Назначение**: Изображения новостей (загруженные пользователем)
- **Картинки**: Автоматически сгенерированные имена по timestamp (1781002918303.jpg)
- **Использование**: Через API (`/images/img_n/{filename}`)

## Как работает сервер (siss.py)

### Метод `serve_images()`
1. Сначала ищет картинку в `images/{filename}` (для logo.png, товаров)
2. Если не нашел — ищет в `images/img_n/{filename}` (для новостей)
3. Если и там нет — использует fallback (`images/img_n/400.png`)

### Метод `save-news` (POST)
- Загружает картинки в `images/img_n/{timestamp}.jpg`
- Сохраняет имя файла в JSON новостей

## HTML-страницы

### Страницы с основными изображениями
- `index.html` — использует `images/1.png`, `images/2.png`, `images/3.png`, `images/logo.png`
- `catalog.html` — использует `images/1.png`, `images/2.png`, `images/logo.png`
- `about.html`, `contacts.html`, `actions.html`, `privacy.html`, `delivery.html` — используют `images/logo.png`

### Страница новостей
- `news.html` — использует `images/logo.png` в шапке
- Карточки новостей загружают картинки из `images/img_n/` через JS

## Правильные пути для использования

### Для основных картинок:
```html
<img src="images/logo.png" alt="Логотип">
<img src="images/1.png" alt="Товар">
```

### Для новостных картинок:
```html
<!-- В HTML напрямую не указывать, только через JS -->
<img src="/images/img_n/{filename}" alt="Изображение события">
```

## Предупреждения

1. **Не путать имена**: `img_n` — это отдельная папка, не префикс имени файла
2. **Не использовать img_n для товаров**: Товары всегда в корне images/
3. **Не использовать корень images/ для новостей**: Новости всегда в img_n/

## Примеры

### Правильно:
```html
<!-- Логотип на всех страницах -->
<img src="images/logo.png" class="logo">

<!-- Товары в каталоге -->
<img src="images/1.png" alt="Рука Барона Земо">

<!-- Новостная картинка (через JS) -->
<img src="/images/img_n/1781002918303.jpg" class="news-image">
```

### Неправильно:
```html
<!-- ❌ Не так! -->
<img src="images/img_n/logo.png" alt="Логотип">  <!-- logo.png не в img_n! -->

<!-- ❌ Не так! -->
<img src="images/1781002918303.jpg" alt="Новость">  <!-- Новостные картинки не в корне! -->
```
